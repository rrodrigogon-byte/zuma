# Como ver o SetPoint

## Opção A — Ver no seu computador (mais rápido)
1. Instale o **Node.js** (uma vez): https://nodejs.org → baixe a versão **LTS** e instale (Avançar/Concluir).
2. Descompacte o arquivo do SetPoint.
3. **Mac:** clique duas vezes em **`ABRIR-no-Mac.command`**.
   **Windows:** clique duas vezes em **`ABRIR-no-Windows.bat`**.
4. O navegador abre sozinho em **http://localhost:3000**. Pronto!
   - Site público: a página inicial.
   - Painel da organização: **http://localhost:3000/admin.html** — login **admin / agroopen2026**.

> Só você (nesse computador) enxerga assim. É ideal para conferir como ficou.

## Opção B — Publicar online (link para compartilhar com a diretoria)
Para gerar um endereço na internet (ex.: `https://setpoint.onrender.com`), siga o **GO-LIVE.md** — em resumo:
1. Criar conta grátis no **Render** (render.com) e no **GitHub**.
2. Subir o projeto no GitHub e, no Render, **New → Blueprint** (ele lê o `render.yaml` já incluso).
3. Definir a senha do admin e dar **Deploy**. Em minutos sai o link público.

Posso te guiar nesse processo passo a passo quando quiser.
